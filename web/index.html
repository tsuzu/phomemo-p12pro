プレビュー

プリンタ接続

セルフテストはプリンタ内蔵パターンを印字します。出れば機構・テープ・ヘッドは正常で、 問題はこちらのジョブ側。出なければテープ装填 (裏表) や機構側の問題です。

デバイスが見つからないとき: ①プリンタがスマホの Print Master アプリと 接続中だと検出できません (アプリを閉じるか、スマホの Bluetooth を OFF にしてください)。 ②OS の Bluetooth 設定でのペアリングは Web Bluetooth には無関係です。 ③上の「全てのデバイスを表示」を有効にすると、名前で選んで接続できます。
"Unsupported device" と出るとき (主に Mac): macOS の Bluetooth 設定でプリンタを ペアリング済みだと Chrome が接続を拒否することがあります。システム設定で 「このデバイスの登録を解除」してから、ページのピッカーだけで接続してください。
